# 📌 项目简介

基于 Hugo 静态网站生成器和 **hugo-theme-reimu** 主题构建的个人博客。该主题以东方 Project 的博丽灵梦为设计灵感,采用二次元风格,提供了完整的功能支持和良好的用户体验。博客支持暗黑模式、响应式设计、代码高亮、数学公式、评论系统等多种功能,适合个人博客、作品展示等场景使用。

# ✨ 功能展示

## 🔧 基础功能

| 功能 | 说明 |
|------|------|
| ✨ 完整的博客功能 | 支持文章发布、分类、标签、归档等 |
| 🔄 兼容 Hugo 0.124.0 及以上版本 | 基于最新 Hugo 版本构建 |
| 📱 响应式布局 | 完美适配 PC、平板、手机等各种设备 |
| 🌙 暗黑模式支持 | 一键切换明暗主题,保护眼睛 |
| 🅰️ i18n 支持 | 支持多语言国际化 |

---

## 💻 代码与数学

| 功能 | 说明 |
|------|------|
| 🖥️ 代码高亮与复制 | 支持多种编程语言语法高亮 |

| 📊 Mermaid 流程图支持 | 支持绘制流程图、时序图等 |
