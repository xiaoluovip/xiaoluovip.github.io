小洛学长2026-03-302026-03-30

📌 项目简介

这是一个基于 Hexo 静态博客框架构建的艺术家个人网站,专为展示艺术作品和博客内容而设计。项目采用完全自定义的 “art” 主题,界面简洁美观,具有完整的博客功能体系。通过集成 Qexo 后台管理系统,实现了可视化内容管理,大大提升了网站的维护效率。

🎬 演示地址

前端展示地址: https://yishu.pages.dev/

后台管理地址: https://qexo-blush-eight.vercel.app/

🔧 常见问题

Q: 如何更换主题配色?

A: 修改主题 CSS 文件中的颜色变量,或通过 Qexo 后台的可视化配色工具进行设置。

Q: 如何添加新的作品分类?

A: 在 Qexo 后台创建新分类,然后在文章中使用该分类即可。

Q: 如何自定义字体?

A: 在主题 CSS 中导入自定义字体,或在 Qexo 后台的字体设置中选择系统字体。

Q: 如何备份网站数据?

A: 定期备份 _config.yml、source/ 目录和 db.json 文件,或使用 Git 进行版本控制。
