📌 项目简介

这是一个为水生动物兽医学研究者量身打造的个人学术博客网站。项目基于 Hexo 静态站点生成器构建，采用 hexo-theme-researcher 专业学术主题，前端使用 Tailwind CSS 和 DaisyUI 组件库进行样式开发。

网站主要服务于水产养殖动物饲养及病害防治领域的学术成果展示，涵盖出版物管理、研究项目展示、个人简历、演讲记录等模块化功能。最特别的地方是内置了超过30种视觉主题风格，访客可以随时切换自己喜欢的界面外观。

主题系统实现

这是这个项目最有意思的部分——主题切换功能的底层原理：

  1. DaisyUI提供了一套完整的主题变量系统
  2. 每个主题定义了一组CSS自定义属性(color/surface/primary等)
  3. 切换时只需修改HTML根元素的data-theme属性
  4. 用户的选择会保存到localStorage，下次访问自动恢复

支持的常用主题包括：light、dark、cupcake、bumblebee、emerald、corporate、synthwave、retro、cyberpunk、valentine、halloween、garden、fantasy、aqua、lofi、pastel、black、luxury、dracula、cmyk、autumn、business、acid、lemonade、nord等等。
