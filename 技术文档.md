# 基于Hexo的资源下载分享博客系统技术文档

## 一、项目概述

本项目是一个基于Hexo静态站点生成器构建的**资源下载分享博客系统**，专注于视频剪辑软件、办公软件等实用资源的分享与下载服务。项目名称为“雷神科技”，采用现代化的Snippet主题构建，提供友好的用户体验和丰富的功能特性。

### 1.1 核心功能特性

| 功能模块 | 功能描述 |
|---------|---------|
| 资源分享 | 支持多种类型资源（AE插件、PR素材、办公软件等）的展示与分享 |
| 网盘链接 | 支持网盘链接挂载，用户可直接跳转下载 |
| 图片展示 | 支持资源预览图展示，包含精美的CSS样式布局 |
| 本地搜索 | 基于JSON内容的本地搜索功能，快速定位文章 |
| 评论系统 | 集成Utterances评论系统，支持GitHub登录评论 |
| 访客统计 | 支持CNZZ、百度统计、谷歌统计等多种统计分析 |
| 响应式设计 | 完美支持PC端和移动端访问 |
| 后台管理 | 提供hexo-admin可视化后台管理界面 |

### 1.2 技术选型

| 技术类别 | 技术栈 | 版本 |
|---------|-------|------|
| 静态站点框架 | Hexo | 8.1.1 |
| 模板引擎 | EJS | 3.1.10 |
| 样式预处理 | Less | 5.0.0 |
| 前端UI框架 | Bootstrap | 5.x |
| 图标库 | Font Awesome | 4.7.0 |
| 构建工具 | Gulp | 5.0.1 |
| 评论系统 | Utterances | - |
| 统计分析 | CNZZ | - |

## 四、主题模板系统详解

### 4.1 模板引擎结构

Snippet主题使用EJS（Embedded JavaScript）作为模板引擎，采用模块化设计将页面拆分为多个可复用的组件。

#### 主布局文件 (`layout.ejs`)

```ejs
<%- partial('_partial/head') %>
<%- partial('_partial/_head-sections/IE',null,{cache: !config.relative_link}) %>
<body>
    <%- partial('_partial/header') %>
    <%- partial('_partial/nav') %>
    <section class="content-wrap">
        <div class="container">
            <div class="row">
                <main class="col-md-8 main-content <%if(is_post()){%>m-post<%}%>">
                    <%- body %>
                </main>
                <% if(theme.toc && is_post()){ %>
                    <%- partial('_partial/toc', null, {cache:false}) %>
                <% } else { %>
                    <%- partial('_partial/sidebar', null, {cache: !config.relative_link}) %>
                <% } %>
            </div>
        </div>
    </section>
    <%- partial('_partial/footer') %>
    <%- partial('_partial/copyright') %>
</body>
</html>
```

#### 文章页面模板 (`post.ejs`)

```ejs
<article class="post">
    <div class="post-head">
        <h1 id="<%= page.title %>">
            <%if(page.link){%>
            <a href="<%- url_for(page.link) %>" target="_blank">
                <%= page.title %></a>
            <%}else{%>
            <%= page.title||'NO Title!' %>
            <%}%>
        </h1>
        <%- partial('_partial/article-meta', {post: page}) %>
        
        <% /* 文章过期提醒功能 */ %>
        <% var diffDays = moment(new Date()).diff(moment(page.date), 'day'); %>
        <% if((theme.warning.days!=0) && diffDays > (theme.warning.days || 300)){ %>
        <p class="fa fa-exclamation-triangle warning">
            <%- theme.warning.text.replace('%d', diffDays) %>
        </p>
        <% } %>
    </div>
    
    <%- partial('_partial/gallery',{post:page})%>
    <div class="post-content">
        <%- page.content %>
    </div>
    
    <% /* 打赏功能 */ %>
    <% if(theme.reward.alipay || theme.reward.wepay){ %>
    <%- partial('_partial/reward') %>
    <% } %>
    
    <% /* 版权声明 */ %>
    <div class="post-footer">
        <% if(theme.declaration.enable){ %>
        <%- theme.declaration.title %>：<%- theme.declaration.tip %>
        <% } %>
    </div>
</article>

<% /* 上一篇/下一篇导航 */ %>
<div class="article-nav prev-next-wrap">
    <% if(page.prev){ %>
    <a href="<%- url_for(page.prev.path) %>" class="pre-post">上一篇</a>
    <% } %>
    <% if(page.next){ %>
    <a href="<%- url_for(page.next.path) %>" class="next-post">下一篇</a>
    <% } %>
</div>

<% /* 评论系统 */ %>
<% if(page.comments){ %>
<div id="comments">
    <%- partial('_vendor/comments/index', {page: page}) %>
</div>
<% } %>
```

```javascript
  function imgsAjax($targetEles) {

    var scrollBottom = getScrollTop() + window.innerHeight;

    }
  }

      $process.style.width =

    }
    // 返回顶部按钮显示/隐藏
    if (getScrollTop() >= 300) {
```

### 5.2 搜索功能脚本 (`search.js`)

实现基于JSON内容的本地搜索功能：

```javascript
// 搜索功能核心逻辑
function search(e) {
  var key = this.value.trim();
  if (!key) {
    render("");
    return;
  }
  // 使用正则表达式匹配关键词
  var regExp = new RegExp(key.replace(/[ ]/g, "|"), "gmi");
  loadData(function (data) {
    var result = data.filter(function (post) {
      return matcher(post, regExp);
    });
    render(result);
  });
  e.preventDefault();
  searchShow();
}

// 加载搜索数据
function loadData(success) {
  if (!searchData) {
    var xhr = new XMLHttpRequest();
    xhr.open("GET", "/content.json", true);
    xhr.onload = function () {
      if (this.status >= 200 && this.status < 300) {
        var res = JSON.parse(this.response || this.responseText);
        searchData = res instanceof Array ? res : res.posts;
        success(searchData);
      }
    };
    xhr.send();
  } else {
    success(searchData);
  }
}

// 渲染搜索结果
function render(data) {
  var html = "";
  if (data.length) {
    html = data.map(function (post) {
      return tpl(searchTpl, {
        title: filter(post.title, "title"),
        path: post.path,
        content: filter(post.text, "content"),
      });
    }).join("");
  } else {
    html = '<div class="tips"><p>没有找到相关结果!</p></div>';
  }
  searchResult.innerHTML = html;
}
```

```javascript
function lazyImage(post) {
  var content = post.content.toString();
  var imgRe = /<img.*?\ssrc=[\'\"]\S+[\'\"]\s.*?>/gim;
  var urlRe = /(http:|https:|\/|\.)\S+(?="\s)/i;
  var imgUrlsArr = content.match(imgRe);
```

```javascript
// Less编译任务
function compileLess() {

    .pipe(less())
    .pipe(rename({ basename: 'style' }))

function lintJs() {
  return src('./themes/snippet/source/js/*.js')
    .pipe(jshint())
    .pipe(jshint.reporter(stylish));

  watch('./themes/snippet/source/js/*.js', lintJs);
```

#### 生产构建任务

```javascript
// CSS优化（添加前缀+压缩）
function optimizeCss() {
  return src('./public/**/*.css')
    .pipe(autoprefixer({
      overrideBrowserslist: [
        'last 10 versions',
        'Firefox >= 20',
        'Opera >= 36',
        'ie >= 9',
        'Android >= 4.0'
      ]
    }))
    .pipe(minifycss())
    .pipe(dest('./public'));
}

// JS压缩
function optimizeJs() {
  return src('./public/js/*.js')
    .pipe(uglify())
    .pipe(dest('./public/js'));
}

// HTML压缩
function optimizeHtml() {
  return src('./public/**/*.html')
    .pipe(htmlclean())
    .pipe(htmlmin({
      removeComments: true,
      collapseWhitespace: true,
      minifyJS: true,
      minifyCSS: true,
      minifyURLs: true
    }))
    .pipe(dest('./public'));
}

// 添加版本号
function addVersion() {
  return src('./public/**/*.html')
    .pipe(rev())
    .pipe(dest('./public'));
}

// 完整构建流程
const build = series(
  parallel(optimizeCss, optimizeJs),
  addVersion,
  optimizeHtml
);
```
